# KONTROL — TC-11 Drop Store

Loja oficial do drop TC-11 da marca KONTROL.

Projeto focado em uma experiência direta:
sem múltiplas páginas, sem distrações, apenas produtos.

---

## 🧱 Sobre o Projeto

A loja foi construída seguindo o conceito:

- Modelo drop
- Página única
- Exposição imediata dos produtos
- Checkout simples
- Interface minimalista

Produtos atuais:

- TC-11 Dryfit Tee — R$ 125,00
